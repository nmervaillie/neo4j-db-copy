== A Neo4j database copy tool over bolt

image:https://github.com/nmervaillie/neo4j-db-copy/actions/workflows/ci.yml/badge.svg["CI", link="https://github.com/nmervaillie/neo4j-db-copy/actions/workflows/ci.yml"]

A development tool useful to copy the data from a Neo4j database to another Neo4j database, or to and from a JSONL file or a directory of parquet files.
Databases can be local or remote.
As the copy is done through the Neo4j driver or a local JSONL export, no admin access to Neo4j is required.

This is useful to copy things around, for example test/reference data from an environment to another.

It has been tested on small to average database sizes.

Note: data deletion and users are not handled.
Indexes and constraints are not copied by default; use `--copy-indexes`.

== Requirements

* JDK 21 or later, to build and run the tool.
* Neo4j 5.x or later on the source and target. Might work on 4.4 versions, untested.
* No admin access is required for a plain copy; only a database user with read access to the source and write access to the target.
* `--lock-source-database` and `--create-target-database` issue admin commands (`SET DATABASE ... ACCESS READ ONLY`, `CREATE DATABASE ...`) and require Neo4j Enterprise Edition with admin privileges.
* APOC Core installed on the target database when the target is a Neo4j database: writing nodes and relationships uses `apoc.create.addLabels` and `apoc.create.relationship` to handle dynamic labels and relationship types. APOC is not needed for the source, nor for JSONL or parquet targets.

== Building

`mvn clean package -DskipTests`

The resulting app can be found in the `target` directory.

== Usage

[source,bash]
----
Usage: neo4j-db-copy [-hV] [--copy-indexes] [--create-target-database] [-lock] [-sp] [-tp] -sa=<sourceAddress> [-sd=<sourceDatabase>]
                     [-su=<sourceUserName>] -ta=<targetAddress> [-td=<targetDatabase>] [-tu=<targetUserName>] [-enp=<excludeNodeProperties>[,
                     <excludeNodeProperties>...]]... [-erp=<excludeRelationshipProperties>[,<excludeRelationshipProperties>...]]...
Copy the content of a Neo4j database to another Neo4j database, a JSONL file, or a parquet directory.
If the source/target address starts with bolt/neo4j, Bolt is used.
If it starts with file, a JSONL file is used.
If it starts with parquet, a directory of parquet files is used.
      --copy-indexes   Copy the indexes and constraints of the source database to the target database, once the data copy is complete (only valid
                         when both source and target use bolt/neo4j). Index creation is asynchronous, indexes may still be populating when the tool
                         exits (env: COPY_INDEXES)
      --create-target-database
                  Create the target database if it does not exist (only valid for bolt/neo4j targets) (env: CREATE_TARGET_DATABASE)
      -enp, --exclude-node-properties=<excludeNodeProperties>[,<excludeNodeProperties>...]
                  Comma-separated list of node properties to exclude from the copy (env: EXCLUDE_NODE_PROPERTIES)
      -erp, --exclude-relationship-properties=<excludeRelationshipProperties>[,<excludeRelationshipProperties>...]
                  Comma-separated list of relationship properties to exclude from the copy (env: EXCLUDE_RELATIONSHIP_PROPERTIES)
  -h, --help      Show this help message and exit.
      -lock, --lock-source-database
                  Set the source database to read-only mode before copying (only valid for bolt/neo4j source) (env: LOCK_SOURCE_DATABASE)
      -sa, --source-address=<sourceAddress>
                  The source address: bolt/neo4j URI for Neo4j, or
                  file:///path/to/file.jsonl for JSONL, or
                  parquet:///path/to/dir for parquet (env: SOURCE_ADDRESS)
      -sd, --source-database=<sourceDatabase>
                  The source database to connect to (used only for bolt/neo4j URIs) (env: SOURCE_DATABASE).
      -sp, --source-password
                  The source database password to connect with (used only for bolt/neo4j URIs) (env: SOURCE_PASSWORD)
      -su, --source-username=<sourceUserName>
                  The source database username to connect as (default: neo4j, used only for bolt/neo4j URIs) (env: SOURCE_USERNAME)
      -ta, --target-address=<targetAddress>
                  The target address: bolt/neo4j URI for Neo4j, or
                  file:///path/to/file.jsonl for JSONL, or
                  parquet:///path/to/dir for parquet (env: TARGET_ADDRESS)
      -td, --target-database=<targetDatabase>
                  The target database to connect to (used only for bolt/neo4j URIs) (env: TARGET_DATABASE).
      -tp, --target-password
                  The target database password to connect with (used only for bolt/neo4j URIs) (env: TARGET_PASSWORD)
      -tu, --target-username=<targetUserName>
                  The target database username to connect as (default: neo4j, used only for bolt/neo4j URIs) (env: TARGET_USERNAME)
  -V, --version   Print version information and exit.
----

Every option can also be set via an environment variable instead of a command-line flag (see `env:` in the
help above) — an explicit command-line flag always takes precedence. This is handy for pulling credentials
from a secret manager: fetch the secret in your wrapper script/CI job and export it into the matching
env var right before invoking the tool, e.g.:

[source,bash]
----
export SOURCE_PASSWORD="$(vault kv get -field=password secret/neo4j/source)"
export TARGET_PASSWORD="$(vault kv get -field=password secret/neo4j/target)"
neo4j-db-copy -sa neo4j+s://source.example:7687 -su neo4j -sd sourcedb \
              -ta neo4j+s://target.example:7687 -tu neo4j -td targetdb
----

Bolt credentials and database names are required only for bolt/neo4j endpoints.
`file:` endpoints are local JSONL files and do not use Neo4j credentials.

The JSON export format is JSONL: one JSON object per line.
Files ending in `.gz` are read and written as gzip-compressed JSONL.
Only `file:` URIs are supported for JSON import/export.

The parquet export writes a directory: one file per distinct node label set under `nodes/`, and
one file per relationship type under `relationships/`. Identity columns are `__dbcopy_id`,
`__dbcopy_labels` for nodes and `__dbcopy_id`, `__dbcopy_source_id`, `__dbcopy_target_id`,
`__dbcopy_type` for relationships. Each file records the Neo4j type of every property in its
parquet footer, so no type information is lost.

Parquet export is experimental: the graph schema is inferred by sampling 1000 nodes per label set
and 1000 relationships per type. If a property does not have one consistent type across a label
set, the export fails rather than writing incorrect data.

A parquet directory can also be used as a source, in which case the property types are read from
the files' footers and nothing is sampled or inferred.

`--copy-indexes` copies the constraints and indexes of the source database to the target database:
once the data copy is complete, the tool replays the source's `CREATE CONSTRAINT` and
`CREATE INDEX` statements on the target, keeping the original names.
Constraint-backed indexes are not copied separately, they are created by their own constraint.
Note that constraint and index creation is asynchronous on the target: the tool does not wait for
the population to finish, so constraints and indexes may still be `POPULATING` when the tool exits.
Some constraint types (property existence, node/relationship key) require Neo4j Enterprise Edition
on the target.

== Examples

[source,bash]
----
# Neo4j -> Neo4j
neo4j-db-copy \
  -sa neo4j+s://source.example:7687 -su neo4j -sp -sd sourcedb \
  -ta neo4j+s://target.example:7687 -tu neo4j -tp -td targetdb

# Neo4j -> JSONL
neo4j-db-copy \
  -sa neo4j+s://source.example:7687 -su neo4j -sp -sd sourcedb \
  -ta file:///tmp/export.jsonl

# Neo4j -> compressed JSONL
neo4j-db-copy \
  -sa neo4j+s://source.example:7687 -su neo4j -sp -sd sourcedb \
  -ta file:///tmp/export.jsonl.gz

# compressed JSONL -> Neo4j
neo4j-db-copy \
  -sa file:///tmp/export.jsonl.gz \
  -ta neo4j+s://target.example:7687 -tu neo4j -tp -td targetdb

# Neo4j -> parquet
neo4j-db-copy \
  -sa neo4j+s://source.example:7687 -su neo4j -sp -sd sourcedb \
  -ta parquet:///tmp/export

# parquet -> Neo4j
neo4j-db-copy \
  -sa parquet:///tmp/export \
  -ta neo4j+s://target.example:7687 -tu neo4j -tp -td targetdb
----
